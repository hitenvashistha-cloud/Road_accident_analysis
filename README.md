# 🚗 Road Accident Analysis

## 📌 Project Overview

Road Accident Analysis is a Business Analytics project developed using Microsoft Excel. The project focuses on analyzing road accident data to identify patterns, trends, and factors associated with road accidents.

The main objective is to transform raw accident data into meaningful insights through data cleaning, analysis, visualization, and dashboard development. The project helps understand accident distribution, severity, road conditions, and other accident-related factors.

## 🎯 Objectives

- Analyze road accident data using Business Analytics techniques.
- Identify accident patterns and trends.
- Examine accident severity and casualties.
- Analyze road types and road surface conditions.
- Understand the influence of weather and lighting conditions.
- Calculate important Key Performance Indicators (KPIs).
- Create an interactive Excel dashboard.
- Generate meaningful insights through data visualization.

## 📊 Dataset Description

The project uses road accident data stored in Microsoft Excel format.

The dataset contains approximately 307,973 accident records and 23 attributes, covering the years 2021 and 2022.

Important attributes include:

- Accident Date
- Accident Severity
- Day of Week
- Road Type
- Road Surface Conditions
- Weather Conditions
- Light Conditions
- Number of Vehicles
- Number of Casualties
- Urban or Rural Area

The dataset provides information required to analyze different aspects of road accidents.

## ⚙️ Project Implementation

The project follows these steps:

1. **Data Collection:** Import the road accident dataset into Microsoft Excel.
2. **Data Cleaning:** Check missing values, duplicates, and inconsistencies.
3. **Data Preprocessing:** Organize and prepare the dataset for analysis.
4. **Data Analysis:** Apply Excel functions, sorting, filtering, and Pivot Tables.
5. **KPI Analysis:** Calculate important accident-related indicators.
6. **Data Visualization:** Create charts and graphs to identify patterns.
7. **Dashboard Development:** Combine KPIs and visualizations into an Excel dashboard.
8. **Result Interpretation:** Analyze the findings and generate meaningful insights.

## 📈 Key Performance Indicators (KPIs)

The project focuses on analyzing important accident-related indicators, including:

- Total Road Accidents
- Total Casualties
- Total Vehicles Involved
- Accident Severity Distribution
- Monthly Accident Trends
